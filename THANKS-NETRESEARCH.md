# Thank you, Netresearch

TYPO3 AI Chat by Webconsulting is a derived work based on
[`netresearch/t3x-nr-mcp-agent`](https://github.com/netresearch/t3x-nr-mcp-agent).

Netresearch DTT GmbH designed and published the original TYPO3 backend chat,
including its conversation model, worker strategy, document extraction,
provider capability checks, upload safeguards and extensive test foundation.
They also created the `nr-llm` abstraction and `nr-vault` integration that this
extension continues to depend on.

We are sincerely grateful. Thank you, Netresearch.

## How attribution is preserved

- the original Git history is retained;
- derived PHP and documentation remain GPL-2.0-or-later;
- existing copyright headers are retained;
- Netresearch is credited in `composer.json` and TYPO3 extension metadata;
- the backend conversation rail and footer visibly thank Netresearch;
- the README, TYPO3 manuals and architecture documentation repeat the credit;
- the migration command thanks Netresearch while safely carrying original data
  into the replacement tables.

Modernization and new code are maintained by Webconsulting. No endorsement by
Netresearch is implied.

Thank you again to the entire Netresearch team for making the starting point
available to the TYPO3 community.
